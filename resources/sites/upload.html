webServ Configuration Reference

📁 Direct C++ Upload Engine

Configured in default.conf:

enable_upload on;
upload_path ./resources/sites/cgi/uploads;

Parses multipart/form-data directly in C++ (HttpResponse.cpp) and responds with HTTP/1.1 201 Created.

🗑️ HTTP DELETE Handling

Configured via allowed methods:

allow_methods GET POST DELETE;

Sends DELETE /cgi/uploads/filename to test resource removal on webServ.
